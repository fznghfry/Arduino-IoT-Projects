# SMART GAS DETECTION SYSTEM

### Arduino Uno | MQ-2 Gas Sensor | Buzzer Alert

## 1. Project Overview

The Smart Gas Detection System is an Arduino-based prototype designed to detect changes in gas concentration using the MQ-2 gas sensor and provide an audible warning through a buzzer.

This project demonstrates the implementation of sensors, microcontrollers, and electronic output devices.

## 2. Hardware Components

| Component | Function |
|---|---|
| Arduino Uno | Main controller |
| MQ-2 Sensor | Gas and smoke detection |
| Buzzer | Audible warning |
| Breadboard | Circuit prototyping |
| Jumper Wires | Electrical connections |

## 3. System Architecture

MQ-2 Sensor → Arduino Uno → Buzzer Alert

## 4. Working Principle

1. MQ-2 reads changes in gas concentration.
2. Arduino receives the sensor readings.
3. Arduino compares the readings with a configured threshold.
4. The buzzer provides an alert when the threshold is exceeded.

## 5. Learning Objectives

- Understand analog sensor readings.
- Learn Arduino input and output.
- Understand threshold-based programming.
- Practice electronic circuit integration.
- Develop basic IoT and automation concepts.
